# 🎓 EduSubmit: Interactive Assignment Submission System

Welcome to the **EduSubmit** project repository! ✨ This system provides a seamless and intuitive platform for students to submit assignments and for instructors to manage, grade, and organize them efficiently. 🚀

## 🌟 Key Features

### 👨‍🎓 For Students
- **Dashboard Overview 📊:** Get a quick glance at upcoming deadlines, recent grades, and overall progress.
- **Easy Submissions 📤:** Upload files with a simple and interactive interface.
- **Submission Details 📝:** View assignment requirements, rubrics, and submission status.
- **Grades & Feedback 💯:** Access detailed feedback and grades for evaluated work.

### 👩‍🏫 For Instructors
- **Instructor Dashboard 📈:** Monitor overall class performance, recent submissions, and pending grading tasks.
- **Grading Interface ✍️:** Efficiently evaluate student submissions, provide comments, and assign grades.
- **Assignment Management 📅:** Create and organize assignments effortlessly.

## 📁 Project Structure
- `index.html` 🏠 - The landing/login page.
- `student-dashboard.html` 🎒 - Main hub for student activities.
- `instructor-dashboard.html` 🎓 - Main hub for instructor activities.
- `assignment-detail.html` 📄 - Specific view for an assignment's details.
- `grading.html` 💯 - Interface for instructors to grade submissions.
- `grades.html` 🏅 - View for students to check their grades.
- `confirmation.html` ✅ - Success page after a submission.
- `css/` 🎨 - Stylesheets for a modern and responsive design.
- `js/` 🧠 - Interactive scripts for dynamic functionality.
- `report/` 📋 - Project documentation and reports.
- `wireframes/` 🖼️ - UI/UX design mockups and wireframes.

## 🚀 Getting Started

To get a local copy up and running, follow these simple steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/sifat-786/submission_system.git
   ```
2. **Open the project:**
   Simply open `index.html` in your favorite web browser! No local server is required for the basic frontend experience. 🌐
